1.2
Tạo Qdrant Collections với schema chuẩn
Qdrant
Tạo 4 collections dưới đây trong Qdrant (port 6333)
Vector size: 1536 (OpenAI text-embedding-3-small) hoặc 768 (Vietnamese BERT)
Distance metric: Cosine cho tất cả
Enable payload indexing cho các filter field: topic, standard_code, source_file
building_codes
QCVN, TCVN — quy chuẩn kỹ thuật bắt buộc
  • standard_code: "QCVN01:2021"
  • topic: "setback" | "density" | "room_size"...
  • article: "Điều 3.1"
  • text: nội dung đoạn văn
  • effective_date: "2021-01-01"
construction_permits
Luật XD, nghị định, quyết định BXD, thủ tục hành chính
  • doc_id: "BXD_940_2026"
  • doc_type: "law" | "decree" | "decision"
  • issued_by: "BXD" | "CP"
  • topic: "permit_procedure"
  • text: nội dung chunk
design_patterns
Mẫu mặt bằng điển hình, design rules, spatial logic
  • house_type: "townhouse" | "villa"
  • lot_width: 4 | 5 | 6 (m)
  • floors: 1 | 2 | 3 | 4
  • room_config: "3br-2bath"
  • layout_json: JSON mặt bằng
materials
Vật liệu xây dựng, thông số kỹ thuật, bảng giá tham khảo
  • material_type: "concrete" | "steel"
  • grade: "B20" | "CB300"
  • properties: JSON thông số
  • unit_price_vnd: số tiền/m³
  • text: mô tả ngắn
# Tạo collection building_codes
curl -X PUT http://localhost:6333/collections/building_codes \
  -H 'Content-Type: application/json' \
  -d '{
    "vectors": { "size": 1536, "distance": "Cosine" },
    "payload_schema": {
      "standard_code": { "data_type": "keyword" },
      "topic":         { "data_type": "keyword" },
      "article":       { "data_type": "keyword" },
      "effective_date":{ "data_type": "text" }
    }
  }'
⏱️ Setup: 2–3 giờ
🔗 Endpoint: localhost:6333

n8n Ingestion Workflows — Đẩy tài liệu vào Qdrant

3 workflows tự động hoá pipeline tài liệu từ file → embed → store

Làm ngay
2.1
Workflow 1: Markdown/Text Ingestion
n8n
Trigger: Webhook POST /webhooks/ingest-md hoặc Watch Files folder rag-doc/
[Trigger: Webhook / Watch Folder] │ body: { file_path, collection, topic, standard_code } ↓ [Read File] │ đọc .md file từ disk ↓ [Function: Split Into Chunks] │ • Split by "---" (markdown sections) hoặc 600-word rolling window │ • Giữ overlap 50 words giữa các chunk │ • Gán metadata: topic, standard_code, chunk_index, total_chunks ↓ [Loop: For Each Chunk] ↓ [OpenAI: Create Embedding] │ model: text-embedding-3-small │ input: chunk.text ↓ [HTTP Request: Qdrant Upsert] │ PUT http://qdrant:6333/collections/{{ collection }}/points │ body: { points: [{ id, vector, payload: { text, topic, ... } }] } ↓ [Response: { ingested: N chunks }]
Node: Watch Files → watch /rag-doc/*.md, trigger khi file mới/thay đổi
Node: Code (JS) → split text: text.split(/\n---+\n/) + sliding window
Node: OpenAI (built-in n8n node) → Embeddings endpoint
Node: HTTP Request → Qdrant REST API upsert
Node: Error Handler → log failures, retry 3 lần
2.2
Workflow 2: PDF Ingestion (BXD PDFs)
n8n
Target files: BXD_940, 942, 974, 975-QD-BXD_17062026.pdf + Giao-Trinh-AutoCad.pdf đang nằm trong rag-doc/docs/
[Trigger: Webhook POST /webhooks/ingest-pdf] │ body: { pdf_path, collection, doc_id, issued_by } ↓ [Extract From File: PDF] │ n8n built-in PDF parser → plain text ↓ [Function: Clean + Chunk] │ • Xóa header/footer lặp lại (số trang, tên công ty) │ • Split theo paragraph, max 500 words/chunk │ • Detect article numbers (Điều X, Khoản Y) → metadata ↓ [Loop: For Each Chunk] ↓ [OpenAI Embedding] ↓ [Qdrant Upsert] │ collection: construction_permits │ payload: { text, doc_id, article, page_num, issued_by }
Dùng n8n node "Extract From File" → chọn type PDF (có sẵn trong n8n)
Regex detect số điều: /(?:Điều|Khoản)\s+\d+/g → lưu vào article field
Batch size 20 points/request để tránh timeout Qdrant

Workflow 4: AI TCVN Compliance Check

Input từ frontend: JSON mô tả thiết kế (room list + sizes, wall heights, corridor widths)
[Webhook: POST /webhooks/tcvn-check] │ body: { │ rooms: [{ type:"bedroom", area:12, width:3 }], │ corridorWidth: 1200, │ stairWidth: 1000, │ floorHeight: 3200, │ windowRatio: 0.15 │ } ↓ [Function: Build Check Queries] │ Tạo list câu hỏi: │ • "diện tích phòng ngủ tối thiểu TCVN" │ • "chiều rộng hành lang tối thiểu QCVN" │ • "chiều cao tầng tối thiểu nhà ở" ↓ [Loop: For Each Query] ├─ [OpenAI Embedding] → vector └─ [Qdrant Search] │ collection: building_codes │ filter: { topic: relevant_topic } │ limit: 3 ↓ [Function: Evaluate Compliance] │ So sánh giá trị thiết kế vs tiêu chuẩn retrieved │ Tạo Violation[] nếu không đạt ↓ [OpenAI Chat: Synthesize Report] │ Prompt: "Đánh giá thiết kế sau theo tiêu chuẩn TCVN..." │ Context: chunks retrieved từ Qdrant ↓ [Response: { violations[], complianceScore, suggestions }]
Dùng Qdrant filter để chỉ tìm trong đúng topic: { "must": [{ "key": "topic", "match": { "value": "room_size" } }] }

Response gọi thẳng từ Go backend → trả về frontend trong <3 giây

// backend/internal/handlers/ai.go
func (h *AIHandler) TcvnCheck(c *gin.Context) {
  var req TcvnCheckRequest
  c.ShouldBindJSON(&req)

  // Gọi n8n webhook
  n8nURL := h.cfg.N8N_BASE_URL + "/webhooks/tcvn-check"
  result, err := h.callN8N(n8nURL, req)

  // Cache 1 giờ với Redis (optional)
  h.cache.Set(cacheKey(req), result, time.Hour)

  c.JSON(200, result)
}
Config: N8N_BASE_URL=http://localhost:5678 trong .env
Timeout: 30s cho tất cả AI requests (LLM inference chậm)
Auth: n8n webhook secret header X-N8N-Secret
