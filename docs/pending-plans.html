W3 — WebGPU Upgrade Path

Detect WebGPU, swap renderer, keep WebGL2 fallback — future-proof rendering pipeline

Priority 0
💡
Tại sao làm ngay? WebGPU cho phép compute shaders, indirect draw calls, và pipeline state caching — kết quả là render 3–5× nhanh hơn với scene phức tạp. Chrome 113+ và Edge đã support stable. Safari Technology Preview đã enable. Đây là foundation cho W4+ features.
Browser ├─ navigator.gpu available? │ ├─ YES → WebGPU Renderer (R3F WebGPU backend) │ │ └─ compute shaders, GPU culling, indirect draw │ └─ NO → WebGL2 Renderer (current Three.js) │ └─ InstancedMesh + BVH (đã implement) │ └─ Capability Store (Zustand sceneSlice) └─ { gpuBackend: "webgpu" | "webgl2", gpuTier: 1|2|3 }

GPU Capability Detection
canvas/3d/gpu/gpuDetect.ts (NEW)
Check navigator.gpu exists + requestAdapter() không null
Detect GPU tier: kiểm tra adapter.limits (maxBindGroups, maxComputeWorkgroupSizeX)
Export detectGpu(): Promise<GpuCapability> — called once on app init
Lưu kết quả vào sceneSlice.gpuBackend
export interface GpuCapability {
  backend: "webgpu" | "webgl2";
  tier:    1 | 2 | 3;          // 1=low, 2=mid, 3=high-end
  maxInstances: number;        // safe InstancedMesh count
  supportsComputeShaders: boolean;
}

export async function detectGpu(): Promise<GpuCapability> {
  if (!("gpu" in navigator)) return WEBGL2_FALLBACK;
  const adapter = await navigator.gpu.requestAdapter();
  if (!adapter) return WEBGL2_FALLBACK;
  // ... check limits, return capability
}

💡
